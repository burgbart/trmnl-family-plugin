02 · Foundations

Accessibility#

A palette is only a design system if it is usable. Every pair the system prescribes is measured, not eyeballed, and tests/test_design_tokens.py fails the build when one drops below its threshold.

Rules
  • 4.5:1 for text, 3:1 for text ≥24px or ≥18.66px bold, 3:1 for control boundaries and meaningful icons (WCAG 2.1 AA, 1.4.3 and 1.4.11).
  • Muted text is text.muted on light and text.secondary on dark. They are not interchangeable: text.secondary is 2.07:1 on white.
  • State colors never carry white text. Use the -surface / -text pair; the solid value is for dots, bars and fills only.
  • Never color alone. Every state also carries a word — "Overdue", "Due soon", "Done".
  • Borders that matter use border.strong. border.subtle is decorative and does not meet 3:1.
  • 14px is the type floor, and 375px is the layout floor.
Interaction
  • Focus is always visible. A 3px color.focus.ring outline at 2px offset on :focus-visible — never outline: none without a replacement. Tab through this page to see it.
  • Every view starts with a skip link to the main landmark.
  • Motion respects prefers-reduced-motion, including smooth scrolling.
  • Controls are labelled: real <label> elements, aria-pressed on toggles, aria-current on active navigation.
  • Hit targets are ≥44px in any view that ships to a phone.

Typography#

Nunito Sans for display — rounded and friendly. Inter for body — crisp and readable. Headings are extrabold with tight leading and scale fluidly, so the hero that reads at 64px on a desktop reads at 40px on a phone without a breakpoint.

Measure is capped at 68 characters, numbers use font-variant-numeric: tabular-nums so times and temperatures do not jitter between refreshes, and 14px is the smallest size the system allows.

05 · Foundations

Motion#

Motion is subtle and functional — short, ease-out, never decorative on data views. Three durations (150/250/400ms), three easings, one default entrance (fade-up).

fade-up entrance400ms · easing.entrance(replay by reloading)
hover lift150ms · easing.standardbuttons, cards
the same lift at 400mstoo heavy for a small element — hover both and compare

Micro-interactions (hover, color) use duration.fast; state changes (toggles, tabs) use duration.normal; entrances and modals use duration.slow with easing.entrance. Nothing loops, nothing bounces, and prefers-reduced-motion disables every animation and transition on this page — including smooth scrolling.

06 · Foundations

Gradient usage#

Two gradients exist — gradient.cta (pink) and gradient.blue — and they have strict jobs. Pink means "act", blue means "decorate".

Do

Primary CTA

Reserved for the one primary action per view. Button text is 16px bold, which clears AA-large on the 3.56:1 pink.

Get started
Do

Icon chips & decorative art

The blue gradient fills circular icon chips, hero illustrations and chart accents — never anything that must be read.

Don't

Behind body copy

Contrast changes across the sweep, so no single text color is safe along its whole length.

Hard to read, never do this.
Don't

Multiple gradients in one view

One gradient element per screen region. A pink CTA plus blue icon chips is fine; competing gradient panels are not — and an invented third gradient is never fine.
